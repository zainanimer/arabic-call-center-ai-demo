KNOWLEDGE BASE
===================
The AI reads these files before it suggests an answer to the agent.
Prices, menus, programs, policies and opening hours are taken ONLY from here.

Folders:
  general\      used for every call (company info, tone, escalation rules)
  hotel\        used for the "Hotels" call sample
  restaurant\   used for the "Restaurant" call sample
  education\    used for the "Educational Platform" call sample
  pizza\        used for the "Pizza Shop" call sample
  (any other call uses ALL folders and the AI works out which business it is)

File types: .txt  .md  .csv  .json  (Excel: File > Save As > CSV UTF-8)
Add, edit or delete files at any time - no restart needed, just replay the call.

THE CURRENT FILES ARE DEMO DATA. Replace them with your real information.
